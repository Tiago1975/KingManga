# KingScan Site

Site estatico pronto para editar.

## Como abrir

Abra o arquivo `index.html` no navegador.

## Onde editar

- `index.html`: estrutura e textos fixos
- `styles.css`: cores, tamanhos e layout
- `script.js`: mangas iniciais, filtros, leitor e painel admin

## Como funciona

O painel Admin salva as alteracoes no `localStorage` do navegador. Depois que sua API estiver online, o arquivo `script.js` pode ser alterado para buscar e salvar mangas pela API do Render.
